# FitTrack

FitTrack is a fitness tracking app I built using Kotlin and Jetpack Compose in Android Studio.

The app allows users to browse different types of workouts, read exercise instructions, and keep track of their completed workouts.

## Features

- Four workout categories: Strength, Cardio, Flexibility, and HIIT
- Exercise descriptions and instructions
- Recommended workout durations and difficulty levels
- Ability to log completed workouts
- Dashboard showing total workouts and minutes
- Recent workout history
- Option to clear workout logs

## Tools Used

- Kotlin
- Android Studio
- Jetpack Compose
- ViewModel
- Git and GitHub

## How to Run

1. Download or clone the project.
2. Open it in Android Studio.
3. Wait for Gradle to finish syncing.
4. Run the app using an Android emulator.

## What I Learned

While working on FitTrack, I practiced creating user interfaces with Jetpack Compose, using Kotlin data classes, managing app state with a ViewModel, and connecting different screens.

I also learned how to use Git commits to track changes and upload my project to GitHub.
